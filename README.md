# Who pays for the rider?

A 2-page memo and a live model on whether a Rs 0-fee food-delivery marketplace (Swish Go) can pay for its riders. Public data only: Swiggy and Eternal Q1 FY27 shareholder letters, plus press.

- Live model (change any assumption): https://faizafham.github.io/rider-economics/
- Memo: https://faizafham.github.io/rider-economics/memo.pdf
- Every input with its source and type (disclosed / press / assumption): [sources.md](sources.md)
- Every number in the memo, with assert checks: `python3 calc.py`

Not affiliated with Swish, Swiggy or Eternal.
